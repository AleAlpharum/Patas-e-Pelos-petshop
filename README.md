# Patas & Pelos Petshop

Projeto acadêmico da disciplina **Fundamentos de Sistemas Web**.

## Conteúdo
- Página inicial com navegação por seções.
- Três categorias: alimentação, brinquedos e acessórios.
- Seis produtos com imagens exportadas do Figma, descrições e preços ilustrativos.
- Dois serviços com descrição, valor e informação sobre tele-busca.
- Layout responsivo em HTML e CSS.

## Arquivos
- `index.html`: página principal do site.
- `imagens/`: seis imagens PNG exportadas do Figma.
- `.nojekyll`: arquivo auxiliar para publicação no GitHub Pages.

## Como visualizar
Abra `index.html` em um navegador. Mantenha a pasta `imagens` no mesmo local do arquivo para que as imagens sejam carregadas.

## Publicar no GitHub Pages
1. Envie todos os arquivos e a pasta `imagens` para a raiz do repositório GitHub.
2. Abra **Settings > Pages** no repositório.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione o branch `main` e a pasta `/ (root)`.
5. Clique em **Save** e aguarde a publicação.
6. Copie o endereço público exibido pelo GitHub Pages.

## Observações
Os preços e contatos são fictícios e ilustrativos. Confira e preencha o campo de autoria antes da entrega.
